# ThodTorrent

Самостоятельный торрент-клиент для Windows x64 и ThodHUB. Rust, нативное окно egui, отдельный процесс librqbit 9.1.0.

При добавлении magnet-ссылки, .torrent-файла или HTTP(S)-ссылки на него программа спрашивает папку. Папку можно запомнить. В таблице отображаются прогресс, объём, скорости и оставшееся время; дополнительные столбцы включаются через «Столбцы». Правый клик по имени открывает действия и сведения о файлах.

Завершённые торренты автоматически останавливаются. Отправка содержимого другим участникам отключена на уровне движка, в том числе во время скачивания. Поле отдачи поэтому остаётся нулевым.

Кнопка «По умолчанию» регистрирует приложение и открывает настройки Windows. Выбор обработчика .torrent и MAGNET подтверждает пользователь в Windows.

Настройки и сессия: THODHUB_DATA_DIR, по умолчанию %LOCALAPPDATA%/ThodHUB/Data/thodtorrent. Скачанные файлы сохраняются в выбранной папке. Закрытие окна завершает движок. Удаление из списка сохраняет файлы; удаление с файлами требует подтверждения.

## Сборка

Rust stable для Windows, LLVM-MinGW либо MSVC. Локальная конфигурация .cargo/config.toml указывает установленный LLVM-MinGW; для другой машины задайте свой linker или собирайте MSVC target. Выполните scripts/make-icon.ps1, затем cargo build --release. Пользователю Rust устанавливать не требуется.

Проверка реальной передачи между двумя локальными BitTorrent-сессиями: thodtorrent.exe --self-test. Данные теста создаются в новой папке %TEMP%/thodtorrent-test-*, рабочие загрузки не используются.

## Ограничения первой версии

Нет RSS, поиска раздач, планировщика, изменения порядка столбцов и индивидуального выбора файлов. Поддержка конкретных раздач зависит от librqbit; основная цель — BitTorrent v1 и magnet BTIH.
