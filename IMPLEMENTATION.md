# ThodTorrent

Новый самостоятельный торрент-клиент Windows x64 для ThodHUB.

## Согласовано

- Отдельное окно; разработчик самостоятельно проверяет приложение.
- Лёгкий интерфейс на Rust поверх готового BitTorrent-движка.
- Открытие magnet-ссылок, файлов .torrent и ссылок на .torrent.
- Выбор папки перед загрузкой и сохранение папки по умолчанию.
- Таблица с именем, визуальным прогрессом и процентом, размером, скачанным объёмом, скоростью скачивания и отдачи, оставшимся временем.
- Настройка видимости столбцов и контекстное меню управления загрузкой.
- Автоматическая остановка завершённых торрентов без дальнейшего сидирования.
- Ассоциации Windows через регистрацию доступности и системный выбор приложения; парные integration/cleanup.
- Настройки и состояние в THODHUB_DATA_DIR; скачанные файлы в выбранной пользователем папке.
- Русский интерфейс по APP-STYLE.md, квадратная иконка и ICO, горизонтальная шапка каталога.
- Проверенная сборка, ZIP, manifest, SHA-256/size; стабильный неизменяемый hub-vX.Y.Z и запись в каталоге main.

## Текущее состояние

Прочитаны правила ThodHUB и контракт. Найден локальный хаб D:/Projects/ThodPROD.
Заявленная в чате папка D:/Every отсутствует в текущем окружении.
Для проекта выделена D:/Projects/ThodTorrent.
Используется librqbit 9.1.0 (Apache-2.0). Rust установлен локально в .tools без изменения PATH.
Реализован и собран выпуск 0.1.0. Результаты проверок описаны в VERIFICATION.md.
