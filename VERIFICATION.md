# Проверка 0.1.0

- Успешная release-сборка Rust для Windows x64.
- Проверен запуск EXE; необходимая libunwind.dll включена в пакет.
- Реальная передача тестового файла 65 536 байт от отдельной локальной BitTorrent-сессии в рабочий процесс приложения. Содержимое совпало побайтно.
- Рабочий процесс автоматически перевёл завершённую загрузку в paused; uploaded_bytes = 0.
- После завершения рабочего процесса и повторного запуска восстановилась завершённая остановленная загрузка.
- Окно ThodTorrent запускается; повторный запуск возвращает код 0 без второго окна.
- Stop-хук завершает окно и рабочий процесс, код 0.
- Integration и cleanup возвращают 0; собственный класс после cleanup отсутствует.
- После повторной регистрации SHAssocEnumHandlers возвращает ThodTorrent и правильный путь к EXE из пакета.
- Валидатор ThodHUB подтвердил manifest, размер, SHA-256 и распаковку ZIP.

Не проверены ручные клики во всех элементах интерфейса, выбор приложения по умолчанию пользователем в настройках Windows, загрузки через публичные трекеры/DHT и все варианты magnet-ссылок. Эти сценарии не заявляются как прошедшие проверку.
